Progetto in Unreal Engine 5.6 relativo al corso Unreal Engine 5 C++ The Ultimate Game Developer Course di Stephen Ulibarri su Udemy.
Il progetto è stato sviluppato utilizzando sia Blueprints che il C++ (Dando la priorità a quest'ultimo) senza alcun ausilio di LLM essendo un progetto a fini di apprendimento.

Comprende :
- Landascape & Foliage
- Utilizzo di Pawn e Character
- Movimento, Controllo e Comportamento dei Character (IK, Controller, Animazioni, Retargeting, AnimationBlueprint, Animation Montage, Bindings dei comandi, ...)
- Collisions & Overlaps
- Pickup Objects, Spawn Objects, Destructible Objects
- Niagara VFX
- Armi ed oggetti impugnabili ed equipaggiabili (Sockets)
- CombatSystem
- HUD e interfaccie (Widgets)
